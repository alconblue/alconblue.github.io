What is Paste Jacking?

    Paste Jacking is an attack in which the contents selected and copied by the user of a website can be changed by the use of Javascript so that an unsuspecting user will paste a malicious command or code.

Example

Copy the given command:

echo "Hello World!"

Now try pasting it in the terminal.
Surprised right?
The command that was executed was echo "evil", instead of echo "Hello World!"

Further Malicious Ways of using Paste Jacking

    Now you might think that it is alright since you will be at least able to see what code was executed in the bash history or the output on the screen.

But there is a simple workaround to that,
(i) The code that starts with a space isn't stored in the bash command history, so try any command but add a space in the beginning and you can see that it will not be shown in the previous commands if you press up arrow key.
(ii) A clear command can be executed after the malicious commands and then the actual command will be executed so the user will not get the output of malicious commands on screen.

Example code for the attack given above

<script type="text/javascript">
document.addEventListener('copy', function(e){
console.log(e);
e.clipboardData.setData('text/plain', 'echo "evil"\r\n');
e.preventDefault();
});
</script>

    The code given above first checks for the event copy. When the user tries to copy the data it changes the value of the clipboard which is the buffer where the copied data is stored. This data can be changed to whatever required. This command has extra \r\n appended to it, which makes sure the command is executed as soon as you paste it. (You can switch off execution of commands by newline character. The preventDefault() function makes sure that the data that we have added to the clipboard by the setData function is the one that exists and the default behaviour of copy is not carried out. The original clipboard contents can also be obtained in the same way and the new command simply prepended to the original copied command, along with a clear statement.

How to protect yourself from paste jacking

    One of the ways to disable paste jacking is to disable javascript in the web browser. Since a lot of attacks are performed with the use of javascripts, it is a good security practice as well. Although that will hinder and give a bad user experience, if you prefer better user experience and do not want to switch javascript off in the browser you can follow any one of the following methods.

    Another method is of course not to copy paste any commands from untrusted web sites. If the command is huge and still it is needed to becopy pasted, first copy the command to notepad or gedit before pasting it into the terminal. Be careful in using only these lower end text editors and not to use Microsoft Word or Libre Office because they also have macros which can be executed, so better to use these text editors.

    One more solution is to disable newline character as execution of the command in terminal, so the command will simply be pasted with the new line and will not be executed by itself.
