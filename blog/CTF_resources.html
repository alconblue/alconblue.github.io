Code to convert Integers to strings

Code for repeated key XOR

    Repeated Key Code

    Place the given hex value to be decrypted in encrypted.py file. Run 1.py which will give you the possible key lengths, place those key lengths one by one in 2.py and run that, which will give you the flag.

Reverse Engineering tools

    GDB: It allows you to set break points in the code and change the flow of the code, while seeing the values in the registers.

    Hopper This software allows you to see the pseudo code for given assembly code which makes the Reverse Engineering task much easier.

Wireshark

    Wireshark allows you to solve questions related to pcap files.

Small Commands

    strings : allows you to check the strings in the file, with grep you can find flags directly present in the file.

    file : shows you the file type.

    hexdump : gives you the hexadecimal values of bytes in file. The first 4 bytes of the file which are the magic numbers. Again useful for file types in questions.

    ltrace : gives you detailed trace of the program running, with the functions being called and their arguments.
