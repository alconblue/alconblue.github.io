What is an origin?

    An origin is the combination of three things: (i) Protocol (ii) Host (iii) Port.
So https://www.example.com/file.html and http://www.example.com/file.html have different origins because of Protocol
http://www.example.com:8000/file.html and http://www.example.com/file.html have different origins because of Ports
http://www.different_example.com/file.html and http://www.example.com/file.html have different origins because of Hosts

What are the origins when you visit a URL?

    Scripts executed in web page with the use of JavaScript have the same origin as the document that opened that opened that URL. So basically if JavaScript or any other method is used to load pages the origin is inherited. Therefore if some malicious website is trying to load the content of your website and you have same origin enabled then the content will not be made available to that malicious website.

Example of malicious attack possible without same origin policy.

     <iframe> HTML tag can be used to load frames from other sites. Following are two iframes:

(i) <iframe src="https://www.google.com">

As you can see it has not been loaded. (ii) <iframe src="http://www.nitk.ac.in">

While this iframe was successfully loaded.

The reason behind this is that Google does not allow cross origin framing while NITK website does.
If cross origin framing is allowed, then the details obtained in this frame can be sent to the malicious website owner and since authentication in majority of the websites is done by cookies, the authentication system can be bypassed.

How to check if website allows cross-origin requests?

    Go to the networks tab of browser (or any other proxy like BurpSuite) and check the response headers for the page/file you are trying to access from the server. There is a field called x-frame-options in the response header of an HTTP Response. There are three possible directives for this:
(i)DENY
(ii)SAMEORIGIN
(iii)ALLOW-FROM https://example.com/

DENY allows cross-origin requests
SAMEORIGIN forces the request and response to be generated from the same origin.
ALLOW-FROM The page can only be displayed in a frame on the specified origin.

Set the x-frame-options as SAMEORIGIN in your servers to avoid attacks like clickjacking and XSS(need CSRF tokens as well, too much detailed to be covered here).

CORS

    CORS (CROSS ORIGIN RESOURCE SHARING) is a new methid which uses addition HTTP header options to be able to share data between different origins securely. Only the data permitted by the server can be accessed by a request from different origin.
